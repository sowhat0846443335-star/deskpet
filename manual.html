คู่มือ Desk Pet

หุ่นสัตว์เลี้ยงตั้งโต๊ะที่มีอารมณ์ของตัวเอง แตะแล้วตอบสนอง บอกให้รู้ว่า Claude Code บนคอมพิวเตอร์ของคุณกำลังทำอะไรอยู่ แสดง CPU, RAM, GPU ของเครื่องได้ และมีเกมให้เล่นด้วยการแตะหัว ใช้กับ Mac, Windows และ Linux ผ่านสาย USB เส้นเดียว

สิ่งที่ต้องมี

รายการรายละเอียด
Desk Petตัวหุ่น (จอ 1.47", เซนเซอร์สัมผัสบนหัว, ลำโพงเล็ก, ไฟ LED)
สาย USB-Cต้องเป็นสายที่ส่งข้อมูลได้ สายชาร์จอย่างเดียวจะใช้ไม่ได้
คอมพิวเตอร์Mac (macOS 11 ขึ้นไป), Windows 10/11 หรือ Linux
Claude Codeไม่บังคับ ถ้าไม่มี หุ่นยังเป็นสัตว์เลี้ยงและแสดงค่าเครื่องได้ตามปกติ
โปรแกรม Desk Petไฟล์เดียว ดาวน์โหลดตามระบบของคุณ (ดูขั้นตอนที่ 2)

เริ่มใช้งาน

  1. เสียบหุ่นเข้ากับคอมพิวเตอร์

    หุ่นจะเล่นเพลงทักทายตอนเปิดเครื่อง แล้วขึ้นดวงตาสีฟ้า

  2. ดาวน์โหลดแล้วดับเบิลคลิก (ครั้งเดียว)

    เครื่องดาวน์โหลด
    Mac ทุกรุ่นDeskPet-Mac.zip 4.6 MB
    Windows 10 / 11DeskPet-Setup-Windows.exe 5.2 MB
    Linux (PC ทั่วไป)DeskPet-Linux-x64 5.0 MB
    Linux (ARM เช่น Raspberry Pi)DeskPet-Linux-arm64 4.9 MB

    เปิดไฟล์ หน้าต่าง Desk Pet จะถามว่า Install Desk Pet? กด Install รอไม่กี่วินาที จะขึ้นข้อความว่าติดตั้งเสร็จและเจอหุ่นแล้ว แค่นั้นเอง ไม่ต้องพิมพ์คำสั่งใดๆ

    Mac

    ดับเบิลคลิก DeskPet-Mac.zip จะได้ Desk Pet Setup แล้วดับเบิลคลิกอีกครั้ง

    ครั้งแรก macOS อาจบอกว่าเปิดไม่ได้ ให้ไปที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย เลื่อนลงไปกด "เปิดต่อไป" (Open Anyway) แล้วเปิดใหม่ ทำครั้งเดียว

    Windows

    ดับเบิลคลิก DeskPet-Setup-Windows.exe

    ถ้าขึ้นหน้าจอสีฟ้า "Windows protected your PC" ให้กด "ข้อมูลเพิ่มเติม" (More info) แล้ว "เรียกใช้ต่อไป" (Run anyway)

    Linux

    คลิกขวาที่ไฟล์ → Properties → เปิด "Allow executing file as program" แล้วดับเบิลคลิก หรือรันใน Terminal

    chmod +x DeskPet-Linux-x64 && ./DeskPet-Linux-x64

    ถ้าเครื่องยังไม่อนุญาตให้ใช้พอร์ต USB ตัวติดตั้งจะขอรหัสผ่านเพื่อตั้งให้ จากนั้นออกจากระบบแล้วเข้าใหม่ 1 ครั้ง

    ตัวติดตั้งจะเปิดโปรแกรมเบื้องหลังให้ทำงานเองทุกครั้งที่เปิดเครื่อง และตั้งค่า Claude Code ให้ส่งสถานะมาที่หุ่น ค่าเดิมในการตั้งค่าของคุณยังอยู่ครบ (สำรองไว้เป็น settings.json.before-deskpet)

  3. ใช้งานได้เลย

    แตะหัวหุ่น 2 ครั้งเพื่อดู CPU / RAM / GPU ของเครื่อง ถ้าใช้ Claude Code ให้เปิดเซสชันใหม่แล้วสั่งงานตามปกติ หุ่นจะเปลี่ยนเป็นหน้าสีส้มเมื่อ Claude เริ่มทำงาน

หุ่นมี 3 โหมด

โหมดสัตว์เลี้ยง

ดวงตาสีฟ้าบนจอดำ หุ่นมองไปรอบๆ กระพริบตา ร้องเพลงเล่นเมื่ออารมณ์ดี เหงาเมื่อไม่มีใครเล่นด้วย และง่วงเมื่อเหนื่อย

โหมด Claude

ใช้กับ Codex CLI

ถ้าเครื่องมี Codex CLI (เครื่องมือเขียนโค้ดของ OpenAI) ตัวติดตั้งจะตั้งค่าให้หุ่นติดตาม Codex ด้วยโดยอัตโนมัติ หุ่นจะเปลี่ยนเป็นหน้าสีขาว ตาสีดำเมื่อ Codex ทำงาน (Claude Code เป็นหน้าสีส้ม) ใช้ท่าทางและเสียงแบบเดียวกับตาราง Claude ด้านบน

STACK — ต่อตึก

บล็อกเลื่อนไปมาด้านบนตึก แตะเพื่อปล่อยลงบนชั้นล่าง ส่วนที่ล้นออกนอกตึกจะถูกตัดทิ้ง ตึกจึงค่อยๆ แคบลง ถ้าวางตรงเป๊ะจะขึ้น PERFECT และไม่โดนตัด ยิ่งต่อสูง บล็อกยิ่งเลื่อนเร็ว ปล่อยพลาดตึกทั้งก้อนถือว่าจบเกม คะแนน = ความสูงของตึก

QUICK! — วัดความไว

แตะเพื่อเริ่ม จอจะเป็นสีแดงพร้อมคำว่า Wait... รอจนจอ (และไฟ LED) เปลี่ยนเป็นสีเขียว แล้วแตะให้เร็วที่สุด หุ่นบอกเวลาเป็นมิลลิวินาที (ms) ยิ่งน้อยยิ่งไว ถ้าแตะตอนยังแดงจะขึ้น "Too soon!" คะแนนสูงสุดคือเวลาที่เร็วที่สุด เหมาะให้เพื่อนร่วมโต๊ะแข่งกัน

FISH — จับปลา

เข็มสีขาวแกว่งไปมาบนแถบด้านบน แตะตอนเข็มอยู่ในโซนสีเขียว ยิ่งใกล้จุดทองตรงกลาง ยิ่งได้ปลาตัวใหญ่ ถ้าโดนจุดทองพอดีจะได้ Golden Koi รอบหนึ่งตกได้ 5 ครั้ง โซนเขียวจะเล็กลงและเข็มเร็วขึ้นทุกครั้ง คะแนน = ความยาวรวมของปลาทั้งหมด (ซม.)

ปลาได้เมื่อ

อัปเดตหรือลบโปรแกรม

ดาวน์โหลดไฟล์ใหม่จากคู่มือนี้ แล้วดับเบิลคลิก จะมีให้เลือก Update หรือ Uninstall (บน Windows: Yes = Update, No = Uninstall) การกด Update ครั้งเดียวจะอัปเดตทั้งโปรแกรมในคอมพิวเตอร์และซอฟต์แวร์ในตัวหุ่น ให้เสียบหุ่นไว้ ระหว่างอัปเดตหุ่น (ประมาณ 15–30 วินาที) จอหุ่นจะค้างหรือดับ ห้ามถอดสาย เสร็จแล้วหุ่นจะรีสตาร์ทเอง และหน้าต่างจะบอกว่า Robot updated

แก้ปัญหาเบื้องต้น

ถอดสายระหว่างอัปเดตหุ่น แล้วจอหุ่นดับ

ไม่ต้องกังวล หุ่นไม่เสีย เสียบสายกลับ แล้วดับเบิลคลิกไฟล์ติดตั้งและกด Update อีกครั้ง โปรแกรมจะหาหุ่นเจอและใส่ซอฟต์แวร์ให้ใหม่ทั้งหมด

หน้ามอนิเตอร์ขึ้น "Waiting for computer..."

หุ่นยังไม่ได้รับค่าจากคอมพิวเตอร์ ตรวจว่าติดตั้งโปรแกรมแล้ว และใช้สาย USB-C ที่ส่งข้อมูลได้ ถ้ายังไม่หาย ให้ดับเบิลคลิกไฟล์ติดตั้งแล้วกด Update หรือรีสตาร์ทคอมพิวเตอร์ 1 ครั้ง

GPU ขึ้น n/a

เครื่องนี้ไม่ให้อ่านค่า GPU เช่น Windows ที่ใช้การ์ด AMD หรือ Intel ค่าอื่นยังแสดงตามปกติ

หุ่นไม่เปลี่ยนเป็นหน้าสีส้มตอนใช้ Claude

หลังติดตั้งครั้งแรก ให้เปิด Claude Code เซสชันใหม่หนึ่งครั้ง ถ้ายังไม่ได้ ให้รัน deskpet status ถ้าขึ้นว่า Robot: not found ให้เปลี่ยนเป็นสาย USB-C ที่ส่งข้อมูลได้ หรือเสียบช่อง USB อื่น ถ้า Bridge: NOT running ให้รัน deskpet restart

Mac บอกว่าเปิดไฟล์ไม่ได้ หรือ "ไม่สามารถตรวจสอบผู้พัฒนา"

ไปที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย เลื่อนลงไปกด "เปิดต่อไป" (Open Anyway) แล้วดับเบิลคลิก Desk Pet Setup อีกครั้ง

Windows: พิมพ์ deskpet status แล้วข้อความขึ้นช้าหรือขึ้นหลัง prompt

เป็นเรื่องปกติ โปรแกรมบน Windows ทำงานแบบไม่มีหน้าต่าง ข้อความจะตามมาหลัง prompt เล็กน้อย กด Enter อีกครั้งเพื่อให้ prompt กลับมา

Linux: Robot not found ทั้งที่เสียบสายแล้ว

ถ้าตอนติดตั้งกดข้ามการขออนุญาต USB หรือยังไม่ได้ออกจากระบบแล้วเข้าใหม่ ให้ออกจากระบบแล้วเข้าใหม่ก่อน ถ้ายังไม่ได้ รัน sudo usermod -aG dialout $USER (Arch ใช้กลุ่ม uucp) แล้วออกจากระบบและเข้าใหม่

ใช้ Claude Code ใน WSL บน Windows

ยังไม่รองรับ เพราะ WSL มองไม่เห็นพอร์ต USB ของ Windows ให้ใช้ Claude Code บน Windows โดยตรง

หน้าการใช้งานขึ้น "No usage data yet"

เปิด Terminal พิมพ์ claude แล้วถามอะไรก็ได้ 1 ข้อ ตัวเลขจะส่งมาที่หุ่นหลัง Claude ตอบ ต้องใช้แพ็กเกจ Claude Pro, Max หรือ Ultra

ตัวเลขขึ้นว่า Stale

ตัวเลขเก่ากว่า 15 นาที เพราะไม่ได้ใช้ claude ใน Terminal ช่วงนั้น ใช้งานต่อเมื่อไรตัวเลขจะอัปเดตเอง

หุ่นร้องเรียกไม่หยุด

แตะหัว 1 ครั้งเพื่อรับทราบ หรือกลับไปตอบ Claude ที่หน้าจอคอมพิวเตอร์

เสียงดังหรือเบาเกินไป

แตะหัว 6 ครั้งเพื่อเปิดหน้าปรับเสียง แล้วแตะทีละครั้งจนได้ระดับที่ต้องการ (ดูหัวข้อ "ปรับเสียง")

Desk Pet Manual

A little desk pet with feelings of its own. It reacts when you touch it, shows what Claude Code is doing on your computer, displays your computer's CPU, RAM and GPU, and has games you play by tapping its head. Works with Mac, Windows and Linux over a single USB cable.

What you need

Getting started

  1. Plug the robot into your computer

    It plays a hello tune when it starts, then shows its blue eyes.

  2. Download and double-click (once)

    ComputerDownload
    Any MacDeskPet-Mac.zip 4.6 MB
    Windows 10 / 11DeskPet-Setup-Windows.exe 5.2 MB
    Linux (regular PC)DeskPet-Linux-x64 5.0 MB
    Linux (ARM, e.g. Raspberry Pi)DeskPet-Linux-arm64 4.9 MB

    Open the file. A Desk Pet window asks Install Desk Pet? Click Install and wait a few seconds until it says it is installed and found the robot. That's it, no commands to type.

    Mac

    Double-click DeskPet-Mac.zip to get Desk Pet Setup, then double-click that.

    The first time, macOS may say it cannot open it. Go to System Settings → Privacy & Security, scroll down, click "Open Anyway", then open it again. You only do this once.

    Windows

    Double-click DeskPet-Setup-Windows.exe

    If a blue "Windows protected your PC" screen appears, click "More info", then "Run anyway".

    Linux

    Right-click the file → Properties → turn on "Allow executing file as program", then double-click it. Or run it in a terminal:

    chmod +x DeskPet-Linux-x64 && ./DeskPet-Linux-x64

    If your account may not use USB ports yet, the installer asks for your password to allow it. Then log out and back in once.

    The installer starts a small background program every time the computer starts and sets up Claude Code to send its status to the robot. Your existing settings stay as they are (a backup is saved as settings.json.before-deskpet).

  3. Ready

    Tap the robot's head twice to see your computer's CPU / RAM / GPU. If you use Claude Code, open a new session and work as usual: the robot's face turns orange when Claude starts working.

The robot has 3 modes

Pet mode

Blue eyes on a black screen. It looks around, blinks, sings when it is happy, gets lonely when nobody plays with it and sleepy when it is tired.

Claude mode

Orange face, black eyes. Switches on by itself when Claude Code works and back when Claude is done. The bottom of the screen says what is happening, e.g. Bash or Thinking.

Monitor mode

Shows the clock and your computer's CPU, RAM, GPU, disk and network speed. Tap the head twice to turn it on or off.

A block slides back and forth above the tower. Tap to drop it on the floor below. Whatever hangs over the edge is cut off, so the tower slowly gets narrower. Land it exactly for a PERFECT: nothing is cut. The higher you build, the faster the block moves. Missing the tower completely ends the game. Score = height of the tower.

QUICK! — reaction test

Tap to start. The screen turns red with "Wait...". Wait until the screen (and the LED) turns green, then tap as fast as you can. The robot shows your time in milliseconds (ms); lower is faster. Tapping while it is still red gives "Too soon!". Your best is your fastest time. Great for challenging your desk neighbours.

FISH — go fishing

A white needle swings along the bar at the top. Tap while it is in the green zone. The closer to the gold centre, the bigger the fish. Hit the gold spot exactly for a Golden Koi. A round has 5 casts, and the green zone gets smaller and the needle faster each time. Score = total length of all your fish (cm).

Every game starts with one tap, restarts with a tap after game over, and closes by itself after 12 seconds without a touch.

The robot remembers each game's best score, even when unplugged. Playing together makes it happier. If Claude Code asks a question or needs permission while you play, the game closes so you can see the message.

Volume

Tap the head 6 times to open the Volume screen with 5 bars. Each tap turns it up one step and the robot plays a sound so you hear the level. After step 5 it goes back to off (Sound off). The screen closes after 5 seconds without a touch. The robot remembers the level, even when unplugged. You can also change it in SETTINGS.

Where the numbers come from

Usage numbers come from Claude Code running in a terminal (the claude command) and update every time Claude answers. If you only use the desktop app, the numbers do not update, but everything else about Claude still shows.

Sleep

(Pet mode only) After 10 minutes with no touch and no Claude work, the robot sings a quiet lullaby and falls asleep. 2 minutes later the screen and light turn off completely. It wakes up when you tap its head twice, touch and hold, or when Claude starts working.

Updating or removing

Download the file again from this manual and double-click it. You can choose Update or Uninstall (on Windows: Yes = Update, No = Uninstall). One Update updates both the app on your computer and the software inside the robot. Keep the robot plugged in. While the robot updates (about 15–30 seconds) its screen freezes or goes dark: do not unplug it. When done it restarts by itself and the window says Robot updated.

Troubleshooting

I unplugged the robot during an update and its screen is dark

Don't worry, it is not broken. Plug it back in, double-click the installer and click Update again. The app finds the robot and puts the software back on it.

The monitor screen says "Waiting for computer..."

The robot is not getting data from the computer. Check that the app is installed and that you use a USB-C data cable. If it continues, double-click the installer and click Update, or restart the computer once.

GPU shows n/a

This computer does not allow reading the GPU, e.g. Windows with an AMD or Intel graphics card. Everything else still shows.

The face does not turn orange when I use Claude

After the first install, open a new Claude Code session once. If it still doesn't work, run deskpet status. If it says Robot: not found, use a USB-C data cable or another USB port. If it says Bridge: NOT running, run deskpet restart.

Mac says the file cannot be opened / "cannot verify the developer"

Go to System Settings → Privacy & Security, scroll down, click "Open Anyway", then double-click Desk Pet Setup again.

Windows: deskpet status prints late or after the prompt

That is normal: the program runs without a window on Windows, so its text appears just after the prompt. Press Enter to get the prompt back.

Linux: Robot not found although it is plugged in

If you skipped the USB permission during install, or have not logged out and in since, log out and back in first. If that does not help, run sudo usermod -aG dialout $USER (Arch uses the uucp group), then log out and back in.

Claude Code in WSL on Windows

Not supported yet, because WSL cannot see Windows' USB ports. Use Claude Code on Windows directly.

The usage screen says "No usage data yet"

Open a terminal, type claude and ask anything once. The numbers reach the robot after Claude answers. Requires a Claude Pro, Max or Ultra plan.

The numbers say Stale

They are more than 15 minutes old because claude was not used in a terminal during that time. They update as soon as you use it again.

The robot keeps calling

Tap its head once to say "got it", or answer Claude on your computer.

Too loud or too quiet

Tap the head 6 times to open the volume screen, then tap once per step until it sounds right (see "Volume").

Touch does not respond

Don't touch the head during the first half second after plugging in, while the sensor calibrates. If it still does not respond, unplug and plug in again.
